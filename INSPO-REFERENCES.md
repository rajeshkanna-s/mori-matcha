# Inspo MCP refinement study

The supplied laptop-screen video is the primary visual target. Inspo was explicitly requested during implementation.

- Fellow, https://fellowproducts.com — tonal product photography, 35/65 text-to-image balance, restrained navigation and a single understated primary action. Retrieved via Inspo `recommend`, `search_screens`, and `get_screen`.
- Blue Bottle, https://bluebottlecoffee.com — calm spacing, product-first hierarchy, clear small typography and simplified mobile navigation. Retrieved via Inspo `search_screens` and `get_screen`.

Applied: improved quiet contrast behind mobile copy, larger mobile controls, consistent navigation spacing and a dominant product composition. Retained the video’s sage palette, pale serif uppercase headlines, process telemetry and numbered chapter rail.

The three custom images are original generated interpretations, not extracted production assets. Motion uses crossfades and camera-like image movement; this version does not reproduce the original physically simulated grinding, liquid pouring, or 3D assembly.
